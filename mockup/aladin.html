    How this frame was made

    1. Asked the NASA/IPAC archive (IRSA) which SPHEREx images cover the star (DR1 + QR3).
    2. Kept one image per visit, all seeing the star at nearly the same wavelength.
    3. Removed the zodiacal light model and put every image on one grid with north up. Two visits saw the sky rotated 180°; this undoes it.
    4. Applied the same brightness stretch (asinh) to every frame, so blinking stays fair.
    5. Moved Gaia DR3's position to each date (proper motion + parallax) and compared it with the measured center of the star.

    Data: NASA/JPL-Caltech/SPHEREx, via NASA/IPAC Infrared Science Archive (IRSA). SPHEREx DR1: doi:10.26131/IRSA678. Astrometry: ESA Gaia DR3.

    Sky map: Aladin Lite (CDS, Strasbourg Observatory) with the SPHEREx DR1 all-sky cube and the DSS2 colour survey (STScI/NASA, coloured by CDS), both served by IRSA.
